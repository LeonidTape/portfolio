# Портфолио — Ismet Sidametovich

Личное портфолио UI/UX и веб-дизайнера. Светлая тема в стиле Apple, три языка: русский, сербский (латиница), английский.

## Структура

```
portfolio/
├── index.html          # Главная: профиль, навыки, опыт, инструменты, образование
├── projects.html       # Работы: карточки разделов и статистика
├── ai.html             # Работа с ИИ
├── video.html          # Видеомонтаж
├── university.html     # Работа на кафедре
├── textme.html         # Контакты
├── content.json        # Исходные данные (справочно, сайт их не читает)
├── assets/
│   ├── css/style.css   # Все стили, цвета и отступы — в :root
│   ├── js/translations.js  # Все переводы (ru / sr / en)
│   ├── js/i18n.js      # Переключение языков
│   ├── js/main.js      # Анимации и галерея
│   └── img/profile-placeholder.jpg  # Фото профиля
```

## Языки

- Переключатель RU / SR / EN в шапке; при первом визите открывается окно выбора языка.
- Выбор сохраняется в `localStorage` (ключ `portfolio-lang`).
- Тексты лежат в `assets/js/translations.js`. Ключ из `data-i18n="..."` в HTML должен существовать во всех трёх языках.
- Атрибуты `alt`, `content` (meta description) и `aria-label` переводятся через `data-i18n-alt`, `data-i18n-content`, `data-i18n-label`.

## Библиотеки

Подключаются с CDN, без сборки:

- **GSAP 3.12.5 + ScrollTrigger** — появление блоков при прокрутке.
- **GLightbox 3.2.0** — просмотр фотографий в галерее кафедры.
- **Inter** (Google Fonts) — основной шрифт.

Если CDN недоступен, сайт остаётся полностью читаемым: анимации просто не включаются.

## Как поменять фото

Замените `assets/img/profile-placeholder.jpg` на своё фото (лучше квадратное или 4:5, от 600 px по стороне). Подробнее — в `PHOTO_GUIDE.md`.

## Как поменять цвета

В начале `assets/css/style.css`, блок `:root`: `--accent` (акцент), `--surface` (фон карточек), `--text` (основной текст).

## Адаптивность

Контрольные точки: 900 px (шапка переносит навигацию, колонки становятся одной), 600 px (мобильная версия), 400 px (компактная).
